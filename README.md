# 동아일보 상시인턴 가이드북

동아일보 상시인턴을 위한 온보딩 가이드북 웹페이지입니다. 빌드 과정 없는 순수 HTML/CSS/JS 정적 사이트로, 브라우저에서 `index.html`을 열거나 정적 호스팅에 그대로 배포하면 됩니다.

## 구성

```
index.html   각 섹션 마크업 (체크리스트/인사시스템/복지제도/회사소개/FAQ/담당자)
styles.css   전체 스타일
script.js    체크리스트 진행률, 아코디언 펼침/접힘 동작
images/      가이드북에 쓰이는 스크린샷 및 로고
```

## 담긴 내용

1. **입사 체크리스트** — 입사 첫 주 완료 항목, 클릭 시 완료 표시 및 진행률 표시
2. **인사시스템** — 재직증명서 발급, 급여·4대보험 조회, 휴가 신청, 의무교육, 사내 와이파이
3. **복지·인사제도** — 사원식당, 휴가 제도
4. **회사소개** — 비전, 사업 영역, 조직도, 관련 채널
5. **자주 묻는 질문** — 급여 / 근태 및 휴가 / 증명서
6. **담당자 연락처**

## 로컬에서 보기

별도 서버 없이 `index.html`을 브라우저로 바로 열어도 되고, 로컬 서버로 띄우려면:

```
python3 -m http.server 8000
```

이후 `http://localhost:8000` 접속.

## 배포 (GitHub Pages)

1. 저장소 **Settings → Pages**
2. Source: `Deploy from a branch` / Branch: `main`, 폴더: `/ (root)`
3. 저장 후 `https://<사용자명>.github.io/<저장소명>/` 에서 접속 가능

## 트래킹

`index.html` 상단에 Google Analytics(gtag) 및 Google Tag Manager 코드가 포함되어 있습니다.
