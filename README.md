# Handoff: 동아일보 상시인턴 가이드북 (최신 편집본 → yoonjy0314/intern_guide)

## Overview
동아일보 상시인턴 온보딩 가이드북 웹페이지의 **최신 편집본**을 GitHub 저장소 `yoonjy0314/intern_guide` (branch `main`)에 반영하기 위한 핸드오프 패키지입니다.

저장소에는 이미 같은 가이드북이 순수 HTML/CSS/JS 정적 사이트(`index.html` / `styles.css` / `script.js` / `images/`)로 존재합니다. 이 패키지의 목적은 **새로 만드는 것이 아니라, 저장소 버전에 빠져 있는 최신 변경분을 반영**하는 것입니다.

## About the Design Files
이 폴더의 HTML 파일들은 **디자인 레퍼런스**입니다 — 최종적인 룩앤필과 동작을 보여주는 프로토타입이며, 그대로 복사해 넣는 프로덕션 코드가 아닙니다.

- `동아일보 상시인턴 가이드북.dc.html` — 작업 원본. 모든 스타일이 **인라인 style 속성**으로 들어가 있습니다. 저장소는 `styles.css`의 클래스 기반 구조이므로, 값(색상·간격·크기)만 옮기고 마크업은 저장소의 기존 클래스 체계(`.check-item`, `.accordion-item`, `.bank-tag` 등)를 그대로 사용하세요.
- `미리보기(단일파일).html` — 이미지까지 모두 인라인된 단일 파일. 브라우저로 열어 최종 결과를 눈으로 확인하는 용도.

## Fidelity
**High-fidelity.** 색상·타이포·간격이 모두 확정된 상태입니다. 저장소 사이트가 이 디자인과 픽셀 단위로 일치하도록 맞춰 주세요.

## 저장소에 반영해야 할 변경분 (delta)

저장소 최신 커밋 기준(`84bbadf`)으로 아래 항목들이 **아직 반영되어 있지 않습니다.**

### 1. 급여계좌 발급 가능 은행 목록 추가 — `index.html` (약 139행 부근)
`.bank-tag` 목록 마지막(`카카오뱅크`) 뒤에 아래 12개를 같은 `.bank-tag` 마크업으로 추가:

```
외환은행, 수협중앙회, 대구은행, 부산은행, 광주은행, 제주은행,
전북은행, 경남은행, 새마을금고, 신협중앙회, 상호저축은행, 우체국
```

태그 스타일(레퍼런스 값): `font-size:11px; padding:3px 10px; border:1px solid #EDEEEC; border-radius:100px; color:#565F6D;`

### 2. 섹션 카드화 — `styles.css`
섹션(01~06) 컨테이너가 기존에는 상단 구분선(`border-top:1px solid #EDEEEC`)만 있는 평면 레이아웃이었습니다. 카드형으로 변경:

```css
max-width: 1040px;
margin: 24px auto;
padding: 48px 40px;
background: #FFFFFF;
border: 1px solid #E6E7E4;
border-radius: 16px;
box-shadow: 0 1px 4px rgba(28, 36, 48, 0.05);
```

카드가 도드라지도록 **페이지 배경색을 `#FFFFFF` → `#F7F8F7`** 로 변경.

### 3. 상단 로고 교체 — `index.html` + `images/`
네비게이션 좌측 로고를 최신 로고 이미지로 교체, 크기 `32px × 32px`. (이미지 파일은 `미리보기(단일파일).html`에서 추출하거나 담당자에게 원본 PNG를 요청하세요.)

### 4. 조직도 부서 설명 높이 정렬 — `styles.css`
회사소개 조직도의 3개 부서(제작부서 / 사업부서 / 경영부서) 설명 문단에 `min-height: 44px;`를 주어, 그 아래 "인턴 운영 부서" 줄이 3개 카드에서 모두 같은 높이에서 시작하도록 맞춤.

부서 설명 문단 스타일: `font-size:12.5px; color:#565F6D; line-height:1.7; margin-bottom:12px; min-height:44px;`

### 5. 휴가 신청 안내 스크린샷 2장 교체 — `images/`
인사시스템 → 휴가 신청 항목의 3번·4번 스크린샷이 새 이미지로 교체되었습니다.
- 3️⃣ `'휴가원(파견사원)' 신청양식 선택` 아래 이미지
- 4️⃣ `결재 상신 (아래 양식 참고하여 작성)` 아래 이미지

최신 이미지는 `미리보기(단일파일).html` 안에 base64로 들어 있습니다.

### 6. 트래킹 코드 정리 — `index.html`
현재 원본에는 **GA4 gtag(`G-4VWFRC7BCB`)** 와 **GTM(`GTM-K58JMHST`)** 이 둘 다 들어 있습니다. 중복 집계 가능성이 있으므로 담당자 확인 후 하나만 남기는 것을 권장합니다. 저장소 반영 시에도 동일하게 판단해 주세요.

- gtag는 `<head>` 바로 다음
- GTM head 스크립트는 `<head>` 상단, noscript iframe은 `<body>` 여는 태그 바로 뒤

## Interactions & Behavior
저장소 `script.js`의 기존 동작을 그대로 유지합니다.
- **체크리스트**: `.check-header` 클릭 → `.is-done` 토글 → `완료 N / M` 라벨 및 `.progress-fill` 너비(%) 갱신
- **아코디언**: `.accordion-header` 클릭 → `.is-open` 토글
- 체크리스트 항목의 본문 내용은 접히지 않고 **항상 노출**
- 관련 채널의 인스타그램 링크는 `target="_blank" rel="noopener"` (iframe 안에서는 인스타그램이 `ERR_BLOCKED_BY_RESPONSE`로 차단되지만, 실제 배포 페이지에서는 정상 동작)
